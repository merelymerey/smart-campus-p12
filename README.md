# AI-Driven Software Engineering — Practice #12: code-based vs low-code

Smart Campus Room Availability Checker built twice from one shared contract.

* `contract/` — user story, six acceptance criteria, inputs/outputs, common test inputs
* `code-based/` — static HTML/JavaScript implementation (Vitest + ESLint)
* `low-code/` — Appsmith implementation (exported app, JSObject source)
* `evidence/` — baseline record, AI prompts and answers, test runs, time log
* `screenshots/` — both implementations and their test results
* `report/` — the report

Live demo (code-based): https://merelymerey.github.io/smart-campus-p12/code-based/
